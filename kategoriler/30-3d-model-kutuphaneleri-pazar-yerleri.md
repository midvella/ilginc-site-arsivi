# 3D Model Kütüphaneleri & Pazar Yerleri

[← Ana dizine dön (README)](../README.md) · [🔎 Alfabetik İndeks](../INDEX.md)

**🔑 Anahtar Kelimeler:** 3D model indirme, 3D model pazarı, ücretsiz 3D model, free 3D assets, model kütüphanesi

- [Poly Haven](https://polyhaven.com) — CC0 lisanslı, kalitesi çok tutarlı model/texture/HDRI kütüphanesi.
- [Sketchfab](https://sketchfab.com/3d-models) — İnteraktif önizlemeli, en büyük 3D model arama motorlarından biri.
- [TurboSquid](https://www.turbosquid.com) — Sertifikalı, stüdyo kalitesinde modellerin satıldığı büyük pazar.
- [CGTrader](https://www.cgtrader.com) — 150.000+ ücretsiz model içeren, rigli karakterlerde güçlü pazar yeri.
- [Free3D](https://free3d.com) — Araç ve bitki modellerinde zengin ücretsiz koleksiyon.
- [Quixel Megascans](https://quixel.com) — Fotogrametri taramalı fotogerçekçi asset kütüphanesi.
- [Quaternius](https://quaternius.com) — Stilize low-poly karakter/araç/çevre paketleri.
- [Kenney Assets](https://kenney.nl/assets) — Binlerce CC0 sprite, model, ikon, ses paketi; oyun geliştiricinin altın standardı.
- [OpenGameArt.org](https://opengameart.org) — 2009'dan beri aktif, lisansa göre filtrelenebilen topluluk arşivi.
- [itch.io Game Assets](https://itch.io/game-assets) — Binlerce ücretli/ücretsiz asset paketi barındıran pazar.
- [Poly Pizza](https://poly.pizza) — Eski Google Poly arşivinden gelen low-poly modeller.
- [3DModels.org](https://3dmodels.org) — Print-ready, UV mapli, özelleştirilebilir model kütüphanesi.
- [CGBookcase](https://www.cgbookcase.com) — Gerçekçi PBR doku ve model kütüphanesi.
- [Blend Swap](https://www.blendswap.com) — Blender kullanıcılarının paylaştığı ücretsiz .blend dosyaları.
- [Chocofur Free](https://chocofur.com/collection/free) — Ticari model mağazasının ücretsiz bölümü.
- [Free3DBase](https://free3dbase.com) — Ücretsiz 3D modeller arşivi.
- [Open3DModel](https://open3dmodel.com) — Ücretsiz model arşivi.
- [3DExport](https://3dexport.com) — Ücretsiz ve ücretli 3D model pazarı.
- [Rigmodels](https://www.rigmodels.com) — Riglenmiş karakter modelleri arşivi.
- [BlenderKit](https://www.blenderkit.com) — Blender içinden erişilen materyal/model/HDRI eklentisi.
- [The Base Mesh](https://thebasemesh.com) — Heykel/modelleme için temiz base mesh modeller.
- [3DSky](https://3dsky.org) — Mobilya, dekor, iç mekan modelleri (3ds Max formatında).
- [NASA 3D Resources](https://nasa3d.arc.nasa.gov) — NASA'nın uzay araçları/gezegen modelleri.
- [Smithsonian 3D Digitization](https://3d.si.edu) — Müze objelerinin taranmış 3D modelleri.
- [MyMiniFactory](https://www.myminifactory.com) — 3D baskıya uygun, bir kısmı ücretsiz model kütüphanesi.
- [Thingiverse](https://www.thingiverse.com) — 3D baskı odaklı, dev ücretsiz model topluluğu.
- [Cults3D](https://cults3d.com) — 3D baskı ve tasarım modelleri pazarı.
- [Sketchfab Store](https://sketchfab.com/store) — Sketchfab'in ücretli/ücretsiz model mağazası bölümü.
- [Renderhub](https://www.renderhub.com) — Render motorlarına özel 3D model pazarı.
- [Toon3D](https://toon3d.com) — Karikatür/cizgi film tarzı 3D modeller.
- [HumanAlloy](https://humanalloy.com) — İnsan/karakter 3D modelleri.
- [Sci-fi 3D Models (CGTrader kategori)](https://www.cgtrader.com/3d-models/sci-fi) — Bilim kurgu temalı modeller.
- [ShareCG](https://www.sharecg.com) — Ücretsiz 2D/3D içerik paylaşım topluluğu.
- [Archibase Planet](https://archibase-planet.com) — Mimari görselleştirme modelleri.
- [3DOcean (Envato)](https://elements.envato.com/3d) — Envato'nun 3D model aboneliği.
- [Yobi3D](https://www.yobi3d.com) — Birden fazla siteyi tarayan 3D model arama motoru.
- [GrabCAD](https://grabcad.com) — Mühendislik/CAD odaklı 3D model topluluğu.
- [Clara.io](https://clara.io) — Tarayıcı tabanlı 3D modelleme ve model kütüphanesi.
- [Rigmodels3D](https://www.turbosquid.com/Search/3D-Models/free) — TurboSquid'in ücretsiz filtre sayfası.
- [Keenan Crane's Model Repository](https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository) — Shader/subdivision testleri için temiz mesh'ler.
