# Araçlar (Asset Üretimi/Düzenleme için)

[← Ana dizine dön (README)](../README.md) · [🔎 Alfabetik İndeks](../INDEX.md)

**🔑 Anahtar Kelimeler:** sprite sheet oluşturma, tilemap editörü, voxel sanat, VFX editörü, oyun asset düzenleme aracı

- [MagicaVoxel](https://ephtracy.github.io) — Ücretsiz voxel sanat aracı.
- [Inkscape](https://inkscape.org) — Ücretsiz vektör çizim yazılımı.
- [Tiled Map Editor](https://www.mapeditor.org) — Ücretsiz, açık kaynak tilemap editörü.
- [TexturePacker](https://www.codeandweb.com/texturepacker) — Sprite sheet oluşturma aracı (ücretsiz sürümü mevcut).
- [Spriter (BrashMonkey)](https://brashmonkey.com) — 2D iskelet animasyon aracı.
- [Effekseer](https://effekseer.github.io) — Ücretsiz, açık kaynak 2D/3D efekt (VFX) editörü.
